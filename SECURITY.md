# Security Policy

## Reporting a Vulnerability

Please do not report security issues in public issues. Use GitHub private
reporting instead:
https://github.com/vulnerable-code-team2-org/vulnerable-code-team1/security/advisories/new

Include a description, steps to reproduce and the affected file. We aim to
respond within 7 days.

## Scope

This repository is an educational project and contains intentionally
vulnerable example code (`vulnerable_examples.py`, `41_scan_stream_default.py`).
